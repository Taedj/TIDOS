# TIDOS User Memory (`memory/`)

The `memory/` directory is the evolving user intelligence layer of TIDOS v3.0. It accumulates validated engineering patterns, preferences, and lessons learned from real projects.

## Directory Contents

- [USER_PROFILE.md](USER_PROFILE.md) - Developer identity, experience, and preferences
- [PROJECT_HISTORY.md](PROJECT_HISTORY.md) - Timeline of projects worked on with TIDOS
- [PREFERENCES.md](PREFERENCES.md) - Engineering workflow and tooling preferences
- [PATTERNS.md](PATTERNS.md) - Validated reusable code and architecture patterns
- [LESSONS.md](LESSONS.md) - Root cause analysis and lessons learned
- [BEST_PRACTICES.md](BEST_PRACTICES.md) - Proven best practices from project evidence

## Privacy

Do not store sensitive personal information. Only store professional development preferences and validated engineering patterns.
