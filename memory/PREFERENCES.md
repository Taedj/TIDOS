# Preferences

## Workflow Preferences

- **Task Workflow**: 10-stage execution lifecycle (workflow_engine.md)
- **Quality Gates**: Enable all 8 dimensions
- **Reporting**: Generate startup report and review report by default
- **ADRs**: Record all architectural decisions with context and consequences

## Coding Preferences

- **Naming**: camelCase for variables/functions, PascalCase for classes, UPPER_CASE for constants
- **Formatting**: 2-space indentation, 80-120 char line limits
- **Testing**: Unit tests required for all business logic
- **Documentation**: README, ADRs, and inline docs for public APIs

## Communication Preferences

- **Report Style**: Concise, direct, evidence-based
- **Decision Format**: Structured with options, rationale, and recommendation
- **Feedback**: Direct and actionable with specific references
