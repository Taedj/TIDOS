# TIDOS Framework Roadmap

---

## 1. Version Releases

### v1.0.0 — Initial Local Framework ✅
- Standard `.tidos/` local project directory structure.
- 10 core specifications, 13 templates, and 18 technology plugins.

### v1.1.0 — Enterprise Evolution System ✅
- OS Freeze Invariant & `.tidos/evolution/` dynamic intelligence layer.
- Silent user methodology observation & RCA post-mortem tracking.

### v2.0.0 — Centralized GitHub Operating System ✅
- Refactored TIDOS into a standalone, centralized GitHub repository platform.
- Top-level modular structure (`kernel/`, `engines/`, `personas/`, `rules/`, `commands/`, `checklists/`, `templates/`, `plugins/`, `prompts/`, `memory/`, `evolution/`, `examples/`, `docs/`).
- Multi-agent consumption protocols for 9 major AI IDEs and CLI tools.
- Future CLI specification.

### v3.0.0 — GitHub Release & Multi-Project Ecosystem ✅
- Renamed `kernel/` to `core/` for semantic clarity.
- Added `config/` directory with `framework.md` as centralized configuration source.
- Added `CODE_OF_CONDUCT.md` for community standards.
- Created installation scripts (`install.sh` / `install.ps1`) for one-command setup.
- Created project starter template for rapid initialization.
- Documented GitHub Release strategy with Semantic Versioning workflow.
- All URLs reference `config/framework.md` instead of hardcoded values.
- Updated all documentation, headers, and cross-references to v3.0.0.

### v3.1.0 — Partner Consultation Mode (2026-09-11)
- Named partners + copyable communication turns; Turn-0 contract, single-box replies.

### v3.2.0 — Platform Robustness (2026-09-11)
- Structural validation, untrusted input boundary, bloat bounds, ledger.

### v4.0.0 — The Federated Cognitive Operating System (2026-10-11) ✅
- Complete blueprint in [docs/THE_BIG_IDEA.md](docs/THE_BIG_IDEA.md).
- Decouples intelligence from model weights, scaffolding 7B/8B models into frontier reasoning engines.
- Autonomous Internet-grounded persona synthesis (`engines/persona_factory_engine.md` v2.0 + `TIDOSMOBILE`).
- Community upstream sync and Zero-Leakage Privacy Firewall (`scripts/sanitizer.py`, `scripts/community_sync.ps1`).
- Colored live terminal streaming & consultation UI (`browser_relay/terminal_ui.py`) with headless default execution.

### Future — Planned
- Native MCP Server implementation (`tidos-mcp-server`) for direct tool-based OS context hydration across all MCP-compatible AI clients.
- Automated GitHub Actions sync bot for cross-repository memory consolidation.

## 2. Project Intelligence Maturity Model

| Level | Stage Name | Description |
| :--- | :--- | :--- |
| **Level 0** | **Uninitialized** | Fresh workspace; no project-specific context loaded. |
| **Level 1** | **Synchronized** | Connected to central TIDOS repository; OS core & rules mounted. |
| **Level 2** | **Learning** | Active project memory, ADRs, and post-task RCA learnings accumulating. |
| **Level 3** | **Adapting** | User preferences & working methodology confirmed (3+ interaction rule). |
| **Level 4** | **Autonomous** | TIDOS operates with deep codebase intelligence and zero-defect execution. |
