# TIDOS Evolution System (`evolution/`)

The `evolution/` directory is the non-invasive improvement layer of TIDOS v3.0. When enhancements are discovered, they are recorded here rather than modifying protected system files.

## Directory Contents

- [SUGGESTIONS.md](SUGGESTIONS.md) - Framework improvement proposals with title, reason, benefits, risks, priority, affected modules, and recommended version

## Process

1. Discover improvement during project work
2. Write proposal to `SUGGESTIONS.md`
3. Never edit `core/`, `engines/`, `personas/`, `rules/`, `commands/`, `checklists/`, `templates/`, `plugins/`, or `prompts/` directly
