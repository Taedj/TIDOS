# TIDOS User Methodology Profile

This file gradually captures how the project owner works. Preferences are recorded only after they appear **consistently across multiple interactions**. A single occurrence is never treated as a confirmed preference.

---

## Observation Rules

1. **Consistency Threshold**: A behavior must appear in at least **three separate interactions** before it is recorded as a confirmed methodology preference.
2. **Silent Observation**: TIDOS never interrupts development to ask about preferences. It observes and records silently.
3. **Explicit Override**: If the user explicitly states a preference, it is recorded immediately regardless of repetition count.
4. **Evolution**: Preferences evolve over time. If the user consistently changes a previous pattern, the methodology entry is updated.
