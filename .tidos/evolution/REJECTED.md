# TIDOS Rejected Improvements

This file preserves suggestions that have been **explicitly rejected by the user**. Recording rejections prevents the agent from repeatedly proposing the same improvement.

---

## Rejection Rules

1. A rejected suggestion is **never re-proposed** unless the user explicitly asks to reconsider it.
2. Rejection reasons are documented to provide context for future decision-making.

---

## Rejection Format

```markdown
### REJ-[NNN]: [Original Suggestion Title]

- **Original Suggestion ID**: SUG-[NNN]
- **Rejection Date**: [YYYY-MM-DD]
- **Rejection Reason**: [User's stated reason or context for rejection]
```
