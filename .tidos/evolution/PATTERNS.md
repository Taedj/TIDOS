# TIDOS Reusable Pattern Library

This file stores production-validated, reusable solution patterns extracted from real project work. A pattern is promoted here only after it has been **successfully reused across two or more modules or features**.

---

## Pattern Lifecycle

1. **Discovery**: A solution approach is first implemented during a feature task.
2. **Validation**: The same approach is successfully reused in a second, independent context.
3. **Promotion**: The pattern is formally documented here with a canonical template.
4. **Evolution**: Existing patterns are improved in-place as better implementations emerge. Patterns are never duplicated.

---
