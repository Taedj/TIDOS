# TIDOS Evolution Roadmap

This file tracks the planned evolution of both TIDOS OS upgrades and project intelligence maturity.

---

## TIDOS OS Release Roadmap

### v1.0.0 — Initial Release ✅
- Core 10-file OS specification (Kernel through Research).
- 13 reusable document templates.
- 18 technology specialization plugins.

### v1.1.0 — Enterprise Evolution System ✅
- OS Freeze invariant separating immutable system from dynamic learning.
- Evolution Layer with 13 artifacts for project intelligence.
- Silent observation protocol for user methodology learning.
- Suggestion/Approval/Rejection workflow for OS self-improvement.

### v1.2.0 — Planned
- Expanded plugin ecosystem (GraphQL, Kubernetes, Rust, Go, Swift/iOS, Tailwind CSS).
- Automated shell scripts in `.tidos/lab/` for framework health auditing.

### v2.0.0 — Vision
- Interactive CLI tool (`npx tidos init`) for automated framework installation.
- Multi-project TIDOS orchestration (shared evolution across monorepo workspaces).

## Project Intelligence Maturity Model

| Maturity Level | Description | Trigger |
| :--- | :--- | :--- |
| **Level 0: Blank** | No project-specific intelligence. Fresh TIDOS installation. | Initial deployment |
| **Level 1: Observing** | Silent observation of user patterns and architecture decisions. | First development session |
| **Level 2: Learning** | Learnings and patterns begin accumulating from completed tasks. | After 3+ completed features |
| **Level 3: Adapting** | User methodology confirmed, best practices validated, suggestions flowing. | After 10+ completed features |
| **Level 4: Autonomous** | TIDOS operates with deep project context, proactive recommendations, and minimal user correction. | Ongoing maturity |
