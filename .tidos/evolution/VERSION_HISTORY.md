# TIDOS Version History

This file maintains a complete SemVer release log for the TIDOS Operating System and Evolution Layer.

---

## Versioning Policy

TIDOS follows [Semantic Versioning 2.0.0](https://semver.org/):

| Version Component | Change Type |
| :--- | :--- |
| **MAJOR** (`X.0.0`) | Breaking architectural changes to OS structure or boot protocol. |
| **MINOR** (`1.X.0`) | New OS capabilities, plugins, templates, or evolution features. |
| **PATCH** (`1.1.X`) | Bug fixes, documentation corrections, wording improvements. |

---

## Release Log

### v1.1.0 — 2026-07-28 (Current)
- **Type**: Minor Release
- **Codename**: Enterprise Evolution System
- **Changes**:
  - Introduced OS Freeze invariant: all system files are now immutable during normal operation.
  - Created `.tidos/evolution/` layer with 13 dynamic intelligence artifacts.
  - Established Suggestion → Approval → Application upgrade workflow.
  - Added silent project observation protocol and user methodology learning.
  - Added end-of-session reflection protocol.
  - Updated TIDSTART.md boot sequence to include Evolution Layer hydration.
  - Updated README.md, CHANGELOG.md, and VERSION.md for v1.1.0.

### v1.0.0 — 2026-07-28
- **Type**: Initial Release
- **Codename**: Foundation
- **Changes**:
  - Complete TIDOS OS: 10 core specifications (kernel.md through research.md).
  - 13 reusable document templates in `.tidos/templates/`.
  - 18 technology specialization plugins in `.tidos/plugins/` plus `plugin_engine.md`.
  - Root entry protocol (TIDSTART.md, README.md, VERSION.md, CHANGELOG.md).
