# TIDOS Reusable Document Templates (`templates/`)

The `templates/` directory contains 13 protected, reusable Markdown document templates for TIDOS (v3.0).

- [architecture.md](file:///d:/work/Dev/TIDOS/templates/architecture.md): Clean Architecture blueprint template.
- [roadmap.md](file:///d:/work/Dev/TIDOS/templates/roadmap.md): Product milestone roadmap template.
- [tasks.md](file:///d:/work/Dev/TIDOS/templates/tasks.md): Task execution backlog template.
- [changelog.md](file:///d:/work/Dev/TIDOS/templates/changelog.md): Keep-a-Changelog template.
- [decisions.md](file:///d:/work/Dev/TIDOS/templates/decisions.md): Architectural Decision Record (ADR) template.
- [lessons.md](file:///d:/work/Dev/TIDOS/templates/lessons.md): RCA post-mortem log template.
- [project_memory.md](file:///d:/work/Dev/TIDOS/templates/project_memory.md): High-level project state digest template.
- [review_report.md](file:///d:/work/Dev/TIDOS/templates/review_report.md): Code self-review report template.
- [quality_report.md](file:///d:/work/Dev/TIDOS/templates/quality_report.md): Master quality audit scorecard template.
- [release_checklist.md](file:///d:/work/Dev/TIDOS/templates/release_checklist.md): Pre-deployment sign-off checklist template.
- [known_issues.md](file:///d:/work/Dev/TIDOS/templates/known_issues.md): Defect and technical debt registry template.
