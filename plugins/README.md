# TIDOS Technology Specialization Plugins (`plugins/`)

The `plugins/` directory contains 18 protected technology plugins and domain specifications for TIDOS (v3.0).

---

## Directory Components

- [flutter.md](/plugins/flutter.md): Flutter & Dart cross-platform specification.
- [firebase.md](/plugins/firebase.md): Firebase serverless infrastructure specification.
- [firestore.md](/plugins/firestore.md): Firestore database & cost optimization spec.
- [supabase.md](/plugins/supabase.md): Supabase PostgreSQL & RLS specification.
- [android.md](/plugins/android.md): Android Native (Kotlin/Jetpack) specification.
- [desktop.md](/plugins/desktop.md): Desktop cross-platform (Tauri/Electron) specification.
- [web.md](/plugins/web.md): Vanilla HTML5/CSS3 web standards specification.
- [react.md](/plugins/react.md): React frontend SPA/hooks specification.
- [nextjs.md](/plugins/nextjs.md): Next.js App Router & Server Components spec.
- [nodejs.md](/plugins/nodejs.md): Node.js backend microservices specification.
- [python.md](/plugins/python.md): Python PEP 8 & Pydantic services spec.
- [docker.md](/plugins/docker.md): Multi-stage Docker containerization spec.
- [postgresql.md](/plugins/postgresql.md): PostgreSQL 3NF schemas & indexing spec.
- [sqlite.md](/plugins/sqlite.md): Embedded SQLite WAL mode specification.
- [ai.md](/plugins/ai.md): AI pipelines, LLM prompts & RAG spec.
- [github.md](/plugins/github.md): GitHub Actions CI/CD workflow spec.
- [playwright.md](/plugins/playwright.md): Playwright E2E browser testing spec.
- [figma.md](/plugins/figma.md): Figma design system tokens & UI sync spec.
