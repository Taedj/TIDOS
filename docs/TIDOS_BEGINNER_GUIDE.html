What is TIDOS? (Explain Like I'm 5) ما هو TIDOS؟ (شرح مبسط كأنك مبتدئ تماماً)

Imagine you run a software workshop. You have a Master Craftsman (a strong, expensive AI like Claude 3.7 Sonnet or Gemini 2.5 Pro) and several Free Apprentices (fast, free models like OpenCode, Gemini Flash, or local open-source LLMs).

Normally, apprentices make silly mistakes: they edit files without reading them, delete tests, guess commands, and say "All done!" when nothing compiles.

TIDOS is the Workshop Foreman (or Guild Master).
When you work with the Master Craftsman, TIDOS quietly watches, writing down the exact recipes, project structure, successful checks, and your human corrections. Then, when you switch to a Free Apprentice, TIDOS stands behind them, hands them the exact recipe, prevents them from touching code before reading it, and refuses to let them say "done" until tests pass.

The result? You can build entire features for free using weak/free models because TIDOS provides the senior guidance.

تخيّل أنك تملك ورشة برمجية. لديك كبير المعماريين (نموذج قوي ومكلف مثل Claude 3.7 Sonnet أو Gemini 2.5 Pro) ولديك متدربون مجانيون (نماذج مجانية سريعة مثل OpenCode أو Gemini Flash أو نماذج محلية مفتوحة المصدر).

في العادة، المتدربون يرتكبون أخطاء كارثية: يعدلون ملفات لم يقرؤوها أصلاً، يتجاهلون الاختبارات، ويدّعون أنهم «انتهوا» بينما الكود لا يعمل!

هنا يأتي دور TIDOS — إنه بمثابة «مدير الورشة» الخبير.
حين تعمل مع النموذج القوي، يقف TIDOS بصمت ويدوّن في «دماغه» المحلي كل الخطوات الناجحة، طرق الفحص، وكيف صحّحت الأخطاء. وحين تنتقل للعمل مع النموذج المجاني، يعطيه TIDOS «دليل العمل» جاهزاً، ويمنعه من تعديل الكود قبل قراءته، ويرفض إنهاء المهمة دون تشغيل اختبارات المشروع الفعلية.

النتيجة؟ تستطيع برمجة مشاريعك بالكامل بنماذج مجانية 100% وبنفس جودة النماذج العملاقة، لأن TIDOS يوجّهها خطوة بخطوة.

1. LEARN Mode (Strong Models) 1. نمط التعلّم (النماذج القوية)

Claude 3.7, GPT-4o, Pro

Activated automatically when you talk to powerful models. You code naturally. In the background, TIDOS hooks capture your prompts, code diffs, passing tests, and corrections into ~/.tidos/brain.db. It periodically synthesizes these into reusable Playbooks.

يعمل تلقائياً عند استخدام النماذج القوية. تعمل كالمعتاد تماماً. في الخلفية، يسجل TIDOS خطوات الحل الناجحة، ملفات المشروع، وأوامر الاختبار في قاعدة بيانات خاصة بجهازك ~/.tidos/brain.db ثم يحوّلها إلى «خطط عمل» (Playbooks).

2. GUIDE Mode (Weak / Free Models) 2. نمط التوجيه (النماذج المجانية)

OpenCode, Flash, Local

Activated automatically for lightweight or free models. TIDOS injects a dense <4KB brief containing: project architecture facts, relevant learned playbooks, strict "read-before-edit" rules, and exact verification commands. It prevents loops and stops hallucinations cold.

يعمل تلقائياً مع النماذج السريعة والمجانية. يحقن TIDOS موجزاً فائق الدقة (أقل من 4 كيلوبايت) يحتوي على: حقائق المشروع، خطط العمل المناسبة للطلب، قاعدة «اقرأ قبل التعديل»، وأمر التحقق الصارم. هذا يمنع النموذج من التخريف أو الدخول في حلقات مفرغة.

How to "Vibe Code" on a Brand New Project كيف تبدأ مشروعاً جديداً بأسلوب الـ Vibe Coding

"Vibe coding" means you speak in plain human language to your AI agent, focusing on your ideas, while the AI writes the code, designs the UI, and solves bugs. With TIDOS v5.4+, you never need to manually setup git submodules or copy files into your new project!

البرمجة بأسلوب الـ Vibe Coding تعني أن تتحدث باللغة الطبيعية مع الذكاء الاصطناعي، تركز فقط على أفكارك وما تريده، بينما يتولى الذكاء الاصطناعي كتابة الكود وحل المشاكل. مع إصدار TIDOS v5.4+، لم تعد بحاجة لنسخ ملفات أو عمل submodules داخل كل مشروع جديد!

  • 1

    Create your new folder and open your AI tool أنشئ مجلد مشروعك الجديد وافتح أداتك المفضلة

    Create any empty folder anywhere (e.g. mkdir my-cool-app; cd my-cool-app) and open it in Antigravity, OpenCode, Claude Code, Cursor, or VS Code.

    أنشئ مجلداً فارغاً في أي مكان تريده وافتحه داخل Antigravity أو OpenCode أو Claude Code أو Cursor أو VS Code.

  • 2

    Start TIDOS (Just type /tidos-start or START TIDOS) شغّل TIDOS (فقط اكتب /tidos-start أو START TIDOS)

    In your chat window, type /tidos-start (or if your tool is already connected via Tool Scout MCP, it boots automatically!). TIDOS detects your model tier, binds to your project directory, checks for learned playbooks, and pops up the desktop Orb.

    في نافذة المحادثة، اكتب /tidos-start (وإذا كانت أداتك متصلة مسبقاً عبر Tool Scout، سيبدأ TIDOS تلقائياً دون كتابة أي شيء!). يتعرف TIDOS على النموذج ومسار المشروع، ويطلق «الكرة الطافية» (Orb) على شاشتك.

  • 3

    Vibe Code with single-request focus اكتب طلباتك باللغة الطبيعية واستمتع بالبرمجة

    Ask what you want: "Build a responsive landing page with Tailwind and a dark mode toggle" or "/tidos add Google Auth login".
    TIDOS ensures the model creates tests or validation steps, runs them, and refuses to mark the task done until the verification passes.

    اطلب ما تريده بكل بساطة: «ابنِ لي صفحة هبوط متجاوبة باستخدام Tailwind مع زر للوضع الليلي» أو «/tidos أضف تسجيل الدخول عبر Google».
    يتكفل TIDOS بإلزام النموذج بفحص الكود والتأكد من عمله قبل إخبارك بالانتهاء.

  • 4

    Leave a tip for weaker models (Optional) اترك نصيحة للنماذج الأضعف عند الحاجة (اختياري)

    If you just solved a tricky bug with a strong model, type /tidos-note always run npm run build before tests in this repo. TIDOS saves this into project playbooks so future free models will never make that mistake!

    إذا حللت مشكلة معقدة مع نموذج قوي، اكتب /tidos-note شغّل دائماً npm run build قبل الاختبارات في هذا المشروع. يحفظ TIDOS هذه النصيحة لتقرأها النماذج المجانية مستقبلاً.

How TIDOS is Installed for the First Time كيفية تثبيت TIDOS لأول مرة على جهازك

Unlike typical tools that you must reinstall in every project, TIDOS installs ONCE per computer (located at D:\work\Dev\TIDOS on your machine) and stores its brain globally in your user directory (C:\Users\<You>\.tidos\).

على عكس الأدوات التقليدية، يتم تثبيت TIDOS مرة واحدة فقط على جهاز الكمبيوتر (موجود على جهازك في D:\work\Dev\TIDOS) ويخزن «دماغه» ومعلوماته العامة في مجلد المستخدم الخاص بك (~/.tidos/).

Developer View: What is Manual vs. What is Automatic? من منظور المطور: ما الذي يحدث تلقائياً وما الذي يتطلب تدخلك؟

⚡ 100% Fully Automatic ⚡ يعمل تلقائياً بالكامل (بدون أي تدخل)

  • Session & Trace Recording: تسجيل الجلسات والآثار: Every prompt, file edited, check executed, and fix is recorded in ~/.tidos/brain.db. كل أمر، تعديل ملف، واختبار يتم تسجيله تلقائياً في قاعدة البيانات المحلية.
  • Privacy & Secret Redaction: تنقية الأسرار والخصوصية: Passwords, tokens, local paths, emails, and IPs are scrubbed before storage. يتم حجب المفاتيح السرية والمسارات والبريد الإلكتروني تلقائياً قبل حفظ أي بيانات.
  • Model Tier Detection: التعرف على فئة النموذج: TIDOS knows if your current model is strong or weak, picking LEARN or GUIDE mode automatically. يعرف TIDOS نوع النموذج ويختار نمط التعلّم أو التوجيه تلقائياً.
  • Playbook Distillation: استخلاص خطط العمل (Distillation): Distills successful workflows into markdown playbooks in ~/.tidos/playbooks/. يستخرج الإجراءات الناجحة المتكررة ويحولها إلى ملفات توجيه تلقائياً.
  • Read-Before-Edit & Check Enforcement: فرض القراءة قبل التعديل والفحص الإلزامي: Forces weak models to inspect target files first and run checks before completion. يلزم النماذج الضعيفة بقراءة الملفات وتشغيل الاختبارات قبل إعلان الانتهاء.
  • Safe Self-Updates for Patches (v5.4+): التحديث التلقائي الآمن للترقيعات: Tests patch releases (e.g. v5.4.1) in an isolated Git worktree; applies them if all tests pass. يختبر التحديثات الفرعية في فرع معزول ويطبقها تلقائياً إذا نجحت الاختبارات.

🛡️ Manual / Requires Your Decision 🛡️ يدوي / يتطلب قرارك وموافقتك

  • First-Time Tool Connection: ربط الأدوات لأول مرة: You click "Connect" in Tool Scout to wire a new editor (e.g. OpenCode or VS Code). تقوم بالنقر على زر Connect في تبويب Tool Scout لربط محرر جديد.
  • Major/Minor Releases Approval: الموافقة على التحديثات الكبيرة: Minor or major versions (e.g., v5.5 or v6.0) notify you and wait for your explicit click. الترقيات الكبيرة تنتظر نقرتك وموافقتك الصريحة بعد مراجعة الميزات.
  • Autopilot & Tool Install Switches: مفاتيح الأمان الحساسة: Features like unattended autonomous jobs (autopilot) and CLI installs (tool_install) are OFF by default until you toggle them. ميزات مثل تشغيل المهام بالخلفية وتثبيت أدوات النظام تكون مغلقة حتى تفتحها بنفسك.
  • Evolution & Improvement Proposals: قبول مقترحات التطوير: When TIDOS invents a new specialized agent or identifies a broken pattern, it files a proposal in /TIDOSZIT for you to Accept/Reject. عندما يقترح TIDOS إنشاء وكيل مخصص جديد، يقدمه لك كمسودة لتقبله أو ترفضه.
  • One-Click Undo: التراجع بنقرة واحدة (Undo): Any automatic action logged in the Action Journal can be instantly rolled back with an Undo button. أي إجراء نفذه TIDOS يتم تسجيله في سجل الحركات ويمكن التراجع عنه بنقرة واحدة.

The "Solo Leveling" System & Desktop Orb نظام الرتب (Solo Leveling) والكرة الطافية على سطح المكتب

TIDOS is gamified with a Solo Leveling progression system. You don't gain XP from vanity metrics; you gain XP only when verified tasks pass real project checks on the first attempt! If you have to correct the AI repeatedly, XP is deducted.

يحتوي TIDOS على نظام تقدم تفاعلي مستوحى من عالم Solo Leveling. لا تحصل على نقاط الخبرة (XP) جزافاً، بل تكسبها فقط عندما تنجح المهمة وتجتاز اختبارات المشروع الحقيقية من أول محاولة! وإذا قمت بتصحيح الذكاء الاصطناعي بسبب أخطائه، تُخصم نقاط.

🔮 The Floating Desktop Orb (New in v5.4!) 🔮 الكرة الطافية على سطح المكتب (جديد في v5.4)

Whenever you run START TIDOS, a sleek floating orb appears on your desktop. It displays your current Rank, Level, and XP ring. Drag it anywhere you like. Clicking it opens a 4-tab HUD: Journey (stats & 14-day XP chart), Evolution (unlocked subagents & proposals), Solutions (cleared tasks), and Next Moves (daily quests).

عند تشغيل START TIDOS، تظهر كرة شفافة طافية على سطح مكتبك. تعرض رتبتك الحالية، مستواك، وحلقة الـ XP. يمكنك سحبها لأي زاوية تفضلها. عند النقر عليها تُفتح لوحة تحكم سريعة: الرحلة (Journey)، التطور (Evolution)، الحلول (Solutions)، و الخطوات التالية (Next Moves).

How TIDOS Evolves & Tests Itself (Evals / Dungeons) كيف يطور TIDOS نفسه ويختبر قدراته (الزنازين / Dungeons)

How do we know TIDOS actually makes models smarter instead of just adding noise?

TIDOS includes 30 verified coding challenge tasks ("Dungeons") spanning Python, React, Go, and Rust. Every dungeon has a strict test suite that fails completely untouched, and passes only when solved correctly.

Mechanism What it Does Safety Guarantee
Dungeon Benchmark Tests weak models with vs. without TIDOS guidance. Mathematical proof of performance improvement before any rule is kept.
Graduated Trust Every capability starts in "Observe" mode, graduates to "Propose", then "Act with Undo". Nothing gets automatic rights without earning them through successful actions.
Daily Diagnose Inspects failed checks, repeated corrections, and tool errors once a day. Files clear proposals with baseline metrics; never auto-applies without consent.
Isolated Self-Update Clones updates to a separate Git worktree and runs all tests before upgrading. Zero chance of a broken release crashing your active environment; instant 1-click rollback.

كيف نتأكد من أن TIDOS يجعل النماذج أذكى بالفعل بدلاً من إضاعة الوقت؟

يحتوي TIDOS على 30 مهمة برمجية موثقة ومعيارية تسمى «الزنازين» (Dungeons) تشمل Python و React و Go و Rust. كل زنزانة تفشل بالكامل قبل التعديل، ولا تنجح إلا بحل الكود الصحيح واجتياز الفحص.

الآلية ماذا تفعل ضمان الأمان
اختبارات الزنازين (Dungeons) تقارن أداء النموذج المجاني بمفرده مقارنة بأدائه مع توجيه TIDOS. إثبات رياضي قاطع لزيادة نسبة النجاح قبل اعتماد أي قاعدة جديدة.
الثقة المتدرجة (Graduated Trust) تبدأ كل ميزة بمرحلة «المراقبة»، ثم «الاقتراح»، ثم «التنفيذ مع إمكانية التراجع». لا يحصل أي نظام تلقائي على صلاحيات دون إثبات جدارته عبر أدلة حقيقية.
التشخيص اليومي (Diagnose) يفحص الأخطاء المتكررة وأسباب فشل المهام مرة واحدة كل يوم. يقدم لك تقريراً بمقترحات التحسين مع الأرقام، ولا يفرض أي تعديل.
التحديث المعزول والآمن ينسخ التحديث إلى بيئة عمل معزولة (Git worktree) ويختبره بالكامل قبل اعتماده. استحالة تعطل بيئة عملك بسبب تحديث؛ مع زر تراجع فوري (Rollback) بنقرة واحدة.
