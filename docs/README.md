# TIDOS Documentation (`docs/`)

The `docs/` directory contains all platform documentation including installation guides, upgrade protocols, AI tool integration guides, and the future CLI specification for TIDOS v3.0.

## Directory Structure

- `tools/` - AI coding agent integration guides (OpenCode, Claude Code, Cursor, etc.)
- `installation.md` - How to install TIDOS
- `upgrade.md` - How to upgrade TIDOS
- `cli_spec.md` - Future CLI architectural specification
- `architecture_review.md` - Enterprise architecture report
- `repository_tree.md` - Full repository tree
- `dependency_diagram.md` - System dependency map
- `migration_guide.md` - v1.x to v2.0 migration
- `release_notes.md` - v2.0 release notes
